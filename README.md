# Task Manager

**Task Manager** — настольное приложение для создания и управления задачами, написанное на Python с использованием библиотеки Tkinter.

Проект позволяет добавлять задачи, редактировать их, удалять и отслеживать выполнение. Данные сохраняются в JSON-файл, поэтому они остаются доступными после закрытия приложения.

## Возможности

- Создание новых задач.
- Редактирование существующих задач.
- Удаление задач с подтверждением.
- Изменение статуса выполнения задачи.
- Отображение списка всех задач.
- Сохранение и загрузка данных в формате JSON.

Каждая задача содержит следующие поля:
- `id` — уникальный идентификатор.
- `title` — название задачи.
- `description` — описание.
- `status` — статус выполнения.
- `author` — автор задачи.
- `created_at` — дата и время создания.

## Используемые технологии

- **Python** — основной язык программирования.
- **Tkinter** — создание графического интерфейса.
- **JSON** — хранение данных приложения.

## Установка и запуск

1. Скачайте или клонируйте репозиторий:

```bash
git clone https://github.com/Artijetsu/scafander-mode-python
```

2. Перейдите в папку проекта:

```bash
cd PythonCourse
```

3. Запустите приложение:

```bash
python main.py
```

Для работы требуется Python 3.10 или новее. Tkinter входит в стандартную библиотеку Python.

## Хранение данных

Все задачи сохраняются в файле `tasks.json` в формате JSON.

Если файл отсутствует, приложение создает его автоматически. При повторном запуске сохраненные задачи загружаются из файла.

## Архитектура приложения

Проект построен на модульной архитектуре и разделен на четыре основных класса:

- **Task** — модель задачи, содержащая данные и методы преобразования в словарь.
- **StorageManager** — отвечает за загрузку, сохранение, добавление, обновление и удаление задач.
- **Interface** — отвечает за графический интерфейс и взаимодействие с пользователем.
- **TaskManager** — управляет логикой приложения и связывает интерфейс с хранилищем данных.

Такое разделение позволяет независимо работать с логикой приложения, хранением данных и графическим интерфейсом.
